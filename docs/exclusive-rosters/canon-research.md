# Spanish names and adaptation boundaries

The project retains its existing seven regular species and five bosses. Eight new species have been added, using names checked against the publisher's Spanish excerpts. Encounter placement, silhouettes, attacks, statistics and jokes are original game adaptations, not claims of fidelity to book encounters.

| In-game name | Primary Spanish source | What the source actually supports |
| --- | --- | --- |
| Rata | [Book 1 / collected edition excerpt](https://www.penguinlibros.com/es/libros-de-ciencia-ficcion/545343-libro-pack-bienvenido-a-la-mazmorra-carl-el-mazmorrero-el-juicio-final-de-carl-el-libro-de-cocina-del-anarquista-carl-e-9788410466524/fragmento) | Hostile rats attack the group. The short telegraphed lunge is a game design choice. |
| Vigilante de pared | [Book 4 excerpt](https://www.penguinlibros.com/es/libros-de-ciencia-ficcion/617363-libro-el-portal-de-los-dioses-ferales-carl-el-mazmorrero-4-9788410466364/fragmento) | Singular name appears in the extinction tattoo description; the creatures are lizards from the previous floor. Garden placement and flanking are adaptations. |
| Mono talador | [Book 3 excerpt](https://www.penguinlibros.com/es/libros-de-ciencia-ficcion/438539-ebook-el-libro-de-cocina-del-anarquista-de-la-mazmorra-carl-el-mazmorrero-3-9788410466173/fragmento) | Katia recalls fighting these creatures. Singular label normalizes the attested plural. Clothes, axe and circular attack are invented for the game. |

Original illustrations were generated individually with built-in `image_gen` using the prompts in `art-prompts.json`. All eight original transparent PNGs live in `assets/art/enemies/`; delivery WebPs preserve dimensions and alpha. Existing original artwork was not replaced. Combat jokes are original, not quotations.
